about=Export vector layers from QGIS to interactive HTML maps with Leaflet, preserving QGIS symbology and styles. Multi-language support (English/French). Optional dynamic PostgreSQL/PostGIS mode: layers stay connected live to the database via a secure PHP endpoint instead of a static GeoJSON dump. Live WFS (vector) and WMS (raster) layers are loaded directly from the OGC server (CORS must be enabled on the server, e.g. GeoServer). Each vector layer has a clickable attribute table (sort, filter, search, CSV export, map highlighting) and a zoom-to-layer button.
